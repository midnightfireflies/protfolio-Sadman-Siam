# Design notes

This portfolio does not activate two Hugo themes at the same time. Instead, it uses an original custom layout inspired by the strengths of both references supplied by the site owner.

## From Hugo Coder — conceptual inspiration

- Minimal developer-oriented presentation
- Strong centered identity/profile treatment
- Clean typography and restrained interface
- Light/dark theme behavior

Reference: https://github.com/luizdepra/hugo-coder

## From Hugo Introduction — conceptual inspiration

- Full-page introduction
- Smooth single-page navigation
- Section-based portfolio storytelling
- Projects and flexible home sections

Reference: https://github.com/victoriadrake/hugo-theme-introduction

All HTML, CSS, JavaScript, and Hugo templates in this project are custom-written for this portfolio rather than copied from either theme.
